# Outline Journal

> A learning-focused social platform where anyone can document, share, and discover their learning journey.

Outline Journal is a platform designed for people who want to share what they're learning, building, and discovering.

Unlike traditional blogging platforms, Outline focuses on the **learning journey** rather than only publishing polished articles.

---

## ✨ Features

### 👤 User Profiles
- Create a personal profile
- Add bio and skills
- Share your learning journey
- View your published entries

### 📝 Learning Entries
- Create and publish entries
- Add headings and subheadings
- Bullet and numbered lists
- Code blocks
- Images
- Tags
- Drafts

### 🔍 Discover
- Explore learning entries
- Search posts
- Browse categories
- Discover creators

### ❤️ Social
- Like entries
- Comment on entries
- Follow creators
- Save entries for later
